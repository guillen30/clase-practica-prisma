# Documentacion de la practica

El informe contiene el paso a paso de NestJS, Prisma, CRUD y JWT, con capturas
reales de Visual Studio Code y Swagger. Se conserva en tres formatos:

- [Word editable](Informe_clase_practica.docx)
- [PDF](Informe_clase_practica.pdf)
- [Markdown](Informe_clase_practica.md)

[Evidencias](evidencias/) contiene las 20 capturas, los registros de comandos
y el resultado de las 19 pruebas realizadas durante la practica original.
El informe refleja ese desarrollo previo a la publicacion del repositorio.
La organizacion actual de ramas y CI esta explicada en el README principal
y en [CONTRIBUTING.md](../CONTRIBUTING.md).
